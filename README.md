# Семейный Хаб · PWA

Local-first приложение для семейных дел и заметок. Без бэкенда, без сборки, без зависимостей — чистый HTML/CSS/JS. Все данные и фото хранятся в **IndexedDB** на устройстве (лимиты localStorage больше не проблема).

## Быстрая проверка
Просто открой `index.html` в браузере — всё работает и так (service worker в этом режиме молча пропускается).

## Запуск как PWA
PWA требует http(s)-origin. Любой статик-сервер:

```bash
# вариант 1
npx serve .

# вариант 2
python3 -m http.server 8080
```

Открой адрес на телефоне → в меню браузера «Добавить на главный экран» / «Установить приложение». После первого визита работает полностью оффлайн.

## Деплой
Это просто статика — заливай папку целиком на любой хостинг (свой сервер, Netlify, GitHub Pages, Vercel). HTTPS обязателен для установки PWA.

## Что внутри
| Файл | Назначение |
|---|---|
| `index.html` | всё приложение: разметка, стили, логика |
| `manifest.webmanifest` | имя, иконки, цвета, режим standalone |
| `sw.js` | оффлайн-кэш оболочки + кэширование шрифтов |
| `icon-192.png`, `icon-512.png`, `maskable-512.png` | иконки приложения |

## Данные
- Состояние (`kv` → `state`) и фотографии (`img` → Blob) — в IndexedDB `family-hub`.
- Фото сжимаются до 1280px / JPEG 72% перед сохранением.
- При первом запуске автоматически подхватываются данные из localStorage старого прототипа (`family_hub_v3_state`), включая фото, — и старый ключ очищается.

## Обновление версии
При изменении файлов подними версию кэша в `sw.js` (`family-hub-v1` → `-v2`), иначе установленное PWA будет держать старую оболочку.
