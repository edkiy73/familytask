# Семейный Хаб · PWA

Local-first приложение для семейных дел и заметок. Без бэкенда, без сборки, без зависимостей — чистый HTML/CSS/JS. Все данные и фото хранятся в **IndexedDB** на устройстве (лимиты localStorage больше не проблема).

## Быстрая проверка
Просто открой `index.html` в браузере — всё работает и так (service worker в этом режиме молча пропускается).

## Запуск как PWA
PWA требует http(s)-origin. Любой статик-сервер:

```bash
# вариант 1
npx serve .

# вариант 2
python3 -m http.server 8080
```

Открой адрес на телефоне → в меню браузера «Добавить на главный экран» / «Установить приложение». После первого визита работает полностью оффлайн.

## Деплой
Это просто статика — заливай папку целиком на любой хостинг (свой сервер, Netlify, GitHub Pages, Vercel). HTTPS обязателен для установки PWA.

## Что внутри
| Файл | Назначение |
|---|---|
| `index.html` | всё приложение: разметка, стили, логика |
| `manifest.webmanifest` | имя, иконки, цвета, режим standalone |
| `sw.js` | оффлайн-кэш оболочки + кэширование шрифтов |
| `supabase.sql` | настройка облака для синхронизации |
| `icon-192.png`, `icon-512.png`, `maskable-512.png` | иконки приложения |

## Синхронизация между устройствами (Supabase)
Без настройки приложение работает локально на каждом устройстве. Чтобы вся семья видела одни данные:

1. Создайте бесплатный проект на [supabase.com](https://supabase.com).
2. Откройте **SQL Editor**, вставьте содержимое `supabase.sql`, нажмите **Run**.
3. В **Project Settings → API** возьмите `Project URL` и `anon public` ключ.
4. Впишите их в начале `index.html`:
   ```js
   const SB_URL = 'https://xxxx.supabase.co';
   const SB_KEY = 'eyJ…';
   ```
5. Задеплойте, откройте приложение → **Семья** → «Создать семью в облаке». Появится код.
6. На остальных устройствах введите этот код — данные объединятся.

Как это работает: изменения улетают в облако через ~1 сек и мгновенно прилетают на другие устройства (Realtime broadcast + pull). Оффлайн всё работает как раньше; при появлении сети — досинхронизация с умным слиянием (по каждой задаче побеждает более свежая правка, удаления не «воскресают»). Фото ходят отдельно и докачиваются лениво. Доступ к данным в базе возможен только по коду семьи (таблицы закрыты, только RPC) — код никому не показывайте.

## Пуши в закрытое приложение
Серверная часть Web Push (Edge Functions + pg_cron) — в папке `supabase/`, пошаговая настройка в `supabase/PUSH-SETUP.md`. Без неё уведомления работают только при открытом/фоновом приложении.

## Данные
- Состояние (`kv` → `state`) и фотографии (`img` → Blob) — в IndexedDB `family-hub`.
- Фото сжимаются до 1280px / JPEG 72% перед сохранением.
- При первом запуске автоматически подхватываются данные из localStorage старого прототипа (`family_hub_v3_state`), включая фото, — и старый ключ очищается.

## Обновление версии
При изменении файлов подними версию кэша в `sw.js` (`family-hub-v1` → `-v2`), иначе установленное PWA будет держать старую оболочку.
